Guía de Permisos y Roles del Sistema

1. Niveles de Permiso Granulares

Permisos asignables individualmente sobre un archivo o carpeta compartida:

Tabla de Permisos Granulares
Permiso Acciones y Descripción
READ Permite ver y descargar el contenido del archivo o carpeta. No permite modificar, renombrar, subir ni eliminar elementos. Recomendado para invitados o lectores.
WRITE Permite crear, modificar y subir archivos dentro de una carpeta, o editar el contenido de un archivo. Por seguridad, no permite modificar o sobrescribir archivos pertenecientes a otros usuarios a menos que posea permiso de gestión. Recomendado para colaboradores.
DELETE Permite eliminar, ver y descargar el archivo o los elementos dentro de una carpeta compartida. No concede permiso para crear o modificar contenido ajeno. Recomendado para tareas de depuración o limpieza.
MANAGE Concede control total sobre la carpeta o archivo. Permite crear, editar, eliminar y otorgar o revocar permisos a otros usuarios sobre dicho elemento (excepto sobre archivos del Superadministrador).

2. Jerarquía de Roles del Sistema

Reglas globales de acceso asignadas al tipo de cuenta de usuario:

Tabla de Roles Globales
Rol Alcance y Privilegios
USER Usuario Estándar: Administra sus propios archivos y aquellos elementos compartidos donde posea permiso explícito (READ, WRITE, DELETE, MANAGE).
ADMIN Administrador: Posee permiso MANAGE por defecto en todo el sistema. Puede gestionar sus propios archivos y los de usuarios estándar. Regla de Seguridad: No puede modificar, eliminar ni gestionar permisos en archivos propiedad de un Superadministrador.
SUPERADMIN Superadministrador: Rol supremo e intocable. Cuenta con acceso total, incondicional e irrestricto sobre todos los archivos, carpetas y permisos del sistema.
